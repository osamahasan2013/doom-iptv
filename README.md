# DOOM IPTV

تطبيق IPTV كامل لاشتراكات **Xtream Codes** وقوائم **M3U**، يعمل على:
- **الموبايل** (أندرويد كتطبيق APK، وآيفون/أندرويد كتطبيق ويب PWA)
- **التلفزيون** (Android TV / Google TV / Fire TV كتطبيق APK، وأي متصفح تلفزيون)
- **الكمبيوتر** (ويندوز وماك ولينكس كتطبيق سطح مكتب)

تصميم: **أسامة حسن دسوقي — OSAMA HASAN DESOUKY**

## المميزات

**التصفح**
- نفس شكل الواجهة: شريط جانبي (أفلام / مسلسلات / مباشر)، متابعة المشاهدة، المفضلة، الفئات، شبكة بوسترات بالسنة والتقييم.
- بحث فوري في الأفلام والمسلسلات والقنوات معاً، وترتيب (المضاف حديثاً، الاسم، التقييم، السنة).
- إخفاء أي فئة (ضغطة مطولة/كليك يمين على الفئة) مع زر «إظهار المخفي».
- صفحة تفاصيل للفيلم (القصة، الممثلين، المخرج، الإعلان) وللمسلسل (المواسم والحلقات ونسبة المشاهدة لكل حلقة).
- عربي/إنجليزي مع اتجاه RTL، وألوان قابلة للتغيير.

**أكثر من اشتراك**
- إضافة أي عدد من الاشتراكات (Xtream أو M3U).
- وضع **منفصل**: تختار الاشتراك من الشريط العلوي، ولكل اشتراك مكتبته.
- وضع **مدمج**: كل الاشتراكات المختارة في مكتبة واحدة. الفئات بنفس الاسم تتدمج، والعناوين المكررة تصبح **مصادر احتياطية** (لو سيرفر وقع، المشغل يجرّب التاني تلقائياً).
- لوحة متابعة لكل اشتراك: الحالة، تاريخ الانتهاء، **الأيام المتبقية** بلون (أخضر/أصفر/أحمر)، الاتصالات المستخدمة والمسموحة، تاريخ الإنشاء، تجريبي أم لا، وتنبيه في الشريط الجانبي قبل الانتهاء بأسبوع.

**المشغل**
- محركات: hls.js و mpegts.js والمشغل الأصلي، مع تجربة صيغة بديلة تلقائياً (m3u8 ⇄ ts) ثم المصادر الاحتياطية.
- تقديم/تأخير (الخطوة قابلة للتغيير)، شريط تقدم، سرعة من 0.25x إلى 3x.
- الأبعاد: ملائمة، ملء/تكبير، تمديد، 16:9، 4:3، 21:9، الأصلي.
- الإضاءة والصوت (سحب لأعلى/لأسفل على الموبايل: يسار = إضاءة، يمين = صوت؛ سحب أفقي = تقديم؛ نقرتين = ±10 ثواني).
- ملء الشاشة، صورة داخل صورة، مسارات الصوت والترجمة، تحميل ملف ترجمة SRT/VTT، مؤقت نوم، معلومات البث.
- استكمال من حيث توقفت، تشغيل الحلقة التالية تلقائياً، تقليب القنوات (↑/↓ أو CH+/CH-)، دليل البرامج (EPG) وإعادة البث (Catch-up) للقنوات المدعومة.
- يدعم الريموت وأزرار الوسائط على التلفزيون.

**المفضلة والقوائم**
- قائمة «المفضلة» + قوائم خاصة بأسماء من اختيارك، تضيف لها أفلام ومسلسلات وقنوات و**حلقات معينة**.

**التنزيل والتسجيل**
- تنزيل الأفلام والحلقات (أو موسم كامل) للمشاهدة بدون إنترنت، مع إيقاف مؤقت واستئناف وحفظ الملف على الجهاز.
- تسجيل البث المباشر فوراً أو **بجدولة** (وقت بداية ومدة)، وتشغيل التسجيل أو حفظه كملف ‎.ts.

**المشاهدة المتعددة (Multi-View)**
- حتى 4 قنوات على الشاشة **في حدود عدد الاتصالات المسموح في اشتراكك**. التطبيق يقرأ `max_connections` من السيرفر ويرفض فتح بث زيادة عن المسموح، وكذلك التنزيل والتسجيل (التنزيل ينتظر لحد ما يتوفر اتصال).

**الرقابة الأبوية**
- رمز PIN، اختيار **الفئات المسموحة** لكل قسم، حجب فئات البالغين تلقائياً، **حد مشاهدة يومي بالدقائق**، و**ساعات مسموحة** (من/إلى). الإعدادات نفسها محمية بالرمز.

**الوضع النهاري / الليلي**
- زر ☀️/🌙 في الشريط العلوي (وفي القائمة الجانبية على الموبايل)، أو «تلقائي» حسب إعداد الجهاز. المشغل يبقى داكناً دائماً.

**قسم IPTV مجاني**
- قنوات مباشرة عربية وعالمية + أفلام ومسلسلات مجانية، مقسمة: رياضة، أخبار، أفلام، مسلسلات، أطفال، وثائقي، موسيقى، ديني، ترفيه… مع فلتر عربي / عالمي / حسب الدولة.
- المصادر (موثوقة ومفتوحة فقط):
  - iptv-org — روابط عامة متاحة من أصحابها: https://github.com/iptv-org/iptv
  - Free-TV/IPTV — قنوات مجانية رسمية فقط: https://github.com/Free-TV/IPTV
  - Internet Archive — أفلام وكرتون كلاسيكي ملكية عامة، ومسلسلات كلاسيكية برخصة عامة/Creative Commons فقط.
- **فحص يومي تلقائي** (`.github/workflows/free-iptv.yml`): كل يوم يجمع المصادر، يفحص كل رابط، ويحذف أي رابط يفشل في فحصين متتاليين. الروابط الجديدة لا تظهر إلا بعد نجاح فحصها. لو مصدر كامل وقع يوم، تُستخدم آخر نسخة سليمة منه حتى 3 أيام.
- داخل التطبيق: لو رابط توقف أثناء التشغيل يتم إخفاؤه فوراً لمدة 24 ساعة.
- فئة «للبالغين»: مخفية افتراضياً ومحمية بالرقابة الأبوية. المصادر الموثوقة لا تنشر قنوات للبالغين (iptv-org أوقفها منذ يناير 2024).
- ملفات M3U جاهزة لأي مشغل آخر في `free/m3u/` (all, arabic, sports, news …).
- **مهم:** المستودع لازم يكون **Public** علشان التطبيق يقدر يقرأ القائمة من `raw.githubusercontent.com`. قبل أول فحص، القسم يعرض iptv-org مباشرة.

**أخرى**
- كاش للمحتوى وتحديث في الخلفية (سرعة فتح فورية) مع مدة تحديث قابلة للتغيير.
- نسخ احتياطي/استعادة للقوائم والسجل والإعدادات.
- وضع تجريبي (Demo) بدون اشتراك لتجربة الواجهة.

## طرق التشغيل والبناء

### 1) أسهل طريقة: البناء التلقائي على GitHub (APK + ويندوز + ماك + لينكس)
1. ارفع المجلد كمستودع على GitHub.
2. من تبويب **Actions** شغّل «Build DOOM IPTV apps» (أو اعمل tag مثل `v1.0.0`).
3. حمّل الملفات الناتجة من Artifacts (أو من Releases عند استخدام tag):
   - `DOOM-IPTV-android.apk` — للموبايل وأجهزة Android TV / Fire TV (تثبيت يدوي).
   - `DOOM-IPTV-ios-unsigned.ipa` — للآيفون والآيباد (يُوقّع ويُثبّت بـ Sideloadly، انظر أسفل).
   - ‎`.exe` لويندوز، ‎`.dmg` لماك، ‎`.AppImage`/`.deb` للينكس.

> ملف الـ APK الناتج نسخة Debug صالحة للتثبيت المباشر. للنشر على Google Play تحتاج توقيع Release.

### تشغيل التطبيق على الآيفون
**أ) تطبيق حقيقي (IPA) — مطلوب لاشتراكك المدفوع**
1. البناء التلقائي على GitHub بيطلع ملف `DOOM-IPTV-ios-unsigned.ipa`.
2. على كمبيوتر ويندوز أو ماك نزّل **Sideloadly** (أو AltStore)، وصّل الآيفون بالكابل.
3. اسحب ملف الـ IPA في Sideloadly، اكتب Apple ID (يفضل حساب ثانوي)، واضغط Start.
4. على الآيفون: الإعدادات ← عام ← VPN وإدارة الأجهزة ← اختر حسابك ← Trust. ولو طلب «Developer Mode» فعّله وأعد التشغيل.
5. بحساب Apple مجاني التطبيق يشتغل 7 أيام، وبعدها تعيد التوقيع بنفس الخطوات (البيانات لا تضيع). بحساب مطوّر مدفوع (99$ سنوياً) يشتغل سنة كاملة.

**ب) تطبيق ويب (PWA) — للمحتوى المجاني والتجربة**
1. انشر مجلد `www` على Cloudflare Pages.
2. افتح الرابط من Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
3. قسم IPTV المجاني يشتغل كويس لأن أغلب روابطه https. اشتراكات http غالباً لن تعمل في Safari.

### 2) على جهازك
```bash
npm install
npm run electron          # تشغيل نسخة الكمبيوتر
npm run android:init      # إنشاء مشروع أندرويد (مرة واحدة)
npm run android:apk       # بناء APK (يتطلب Android SDK + JDK 21)
npm run dist:win          # مثبّت ويندوز
```

### 3) نسخة الويب (PWA) — مثلاً على Cloudflare Pages
- انشر مجلد `www` كما هو (بعد `npm run libs` ليشتغل المشغل بدون CDN).
- ملاحظة مهمة: معظم سيرفرات IPTV تعمل بـ `http` ولا ترسل ترويسات CORS، والمتصفح يمنع صفحة `https` من الوصول لها. لذلك:
  - استخدم تطبيقات أندرويد/الكمبيوتر (لا يوجد بها هذا القيد) — **الأفضل**.
  - أو انشر `proxy/worker.js` على Cloudflare Workers وضع رابطه في: الإعدادات ← متقدم ← بروكسي للـ API. البروكسي يمرّر بيانات القوائم فقط ويرفض روابط الفيديو.

## ملاحظات تقنية
- في نسخة الويب، التنزيل والتسجيل يعتمدان على أن السيرفر يسمح بـ CORS. في تطبيق أندرويد التنزيل يتم بالمحمّل الأصلي للنظام.
- التسجيل المجدول يعمل طالما التطبيق مفتوح.
- الملفات: `www/js/core.js` (البيانات والاشتراكات)، `player.js` (المشغل)، `features.js` (التنزيل والتسجيل)، `ui.js` (الواجهة)، `css/app.css` (التصميم).
